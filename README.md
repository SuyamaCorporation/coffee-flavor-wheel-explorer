# コーヒー フレーバーホイール エクスプローラー

SCA風のフレーバーホイールをSVGで描画し、テイスティングノートを記録するコーヒー向けツール。

## 機能
- SCA風フレーバーホイール（SVG描画）
  - 内輪: 主カテゴリ（Fruity/Sweet/Nutty/Roasted/Spices/Floral/Sour/Green）
  - 外輪: サブカテゴリ（Berry/Citrus/Caramel/Chocolate 等）
- 外輪クリックで詳細フレーバーリスト表示
- ボタンクリックでテイスティングノートに追加
- 手入力でカスタムフレーバーも追加可能
- localStorage にテイスティングノートを保存・復元
- ×ボタンで個別削除、クリアで全削除

## 対応カテゴリ
Fruity / Sweet / Nutty / Roasted / Spices / Floral / Sour / Green
